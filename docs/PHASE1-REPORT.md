# تقرير تسليم المرحلة ١ — الأساس

وفق صيغة التسليم في الجزء ١٧. التاريخ: ٢٨ سبتمبر ٢٠٢٦.

## ١. ما بُني وما لم يُبنَ

### ما بُني
- **المصادقة والأمان:**
  - دخول بالبريد وكلمة المرور، أو برمز لمرة واحدة.
  - مصادقة ثنائية (TOTP) مع رموز استرداد، إلزامية لأدوار محددة.
  - قفل الحساب بعد محاولات فاشلة، وحدّ لمعدل الطلبات.
  - نسيت/إعادة تعيين كلمة المرور، ودعوة المستخدمين.
  - الجلسات النشطة مع إمكانية إنهائها.
  - تشفير الحقول الحساسة (AES-256-GCM)، وترويسات أمان، وفحص المصدر في طلبات التعديل.
- **تعدد المدارس (المستأجرون):**
  - الفروع والمراحل والصفوف والفصول والأعوام الدراسية.
  - عزل تلقائي لكل استعلام، مُختبر على قاعدة حقيقية.
- **الأدوار والصلاحيات:**
  - ١٩ دوراً نظامياً وأدوار مخصصة.
  - مصفوفة صلاحيات: وحدة × إجراء × نطاق (كل المدرسة / فرع / مرحلة / المسند إليه / سجلاته).
  - إسناد الأدوار مقيّداً بفرع أو مرحلة.
- **سجل التدقيق:**
  - كل إنشاء/تعديل/حذف مسجّل تلقائياً بالمستخدم وIP والمتصفح والقيم قبل وبعد، مع حجب الحقول الحساسة.
  - محمي بمشغّل في قاعدة البيانات يمنع تعديله وحذفه وتفريغه.
  - شاشة عرض بالتصفية والفروقات، وتصدير CSV يُسجَّل بدوره.
- **نظام التصميم:**
  - رموز الألوان الرسمية (فاتح وداكن)، والخط (انظر أدناه)، وجدول الحركات، واحترام «تقليل الحركة».
  - مكونات مشتركة: أزرار، قوائم، نوافذ، شارات، مفاتيح، إشعارات مع «تراجع»، هياكل التحميل، الحالات الفارغة.
- **إطار التطبيق:**
  - شريط جانبي قابل لتغيير العرض والطي، بشجرة صفحات تدعم السحب.
  - تبويبات، ولوحة أوامر (⌘K) مع بحث شامل، ومؤشرات حضور الزملاء.
  - شارة «بيانات تجريبية» ظاهرة دائماً.
- **الصفحات:**
  - محرر كتل مع أمر «/» والإشارات @ والمعادلات والجداول والصور.
  - الأيقونات والأغلفة، والمشاركة بمستويات وصول، وقفل الصفحة.
  - النسخ السابقة واسترجاعها، والمهملات والاسترجاع.
- **قواعد البيانات:**
  - ٦ عروض: جدول، لوحة، تقويم هجري/ميلادي، معرض، قائمة، خط زمني.
  - ١٩ نوع خاصية، منها العلاقات والتجميعات والمعادلات بأسماء عربية.
  - التصفية والفرز والتجميع والحسابات، والقوالب، والأتمتة.
  - المعاينة الجانبية، والتصدير إلى Excel وCSV والطباعة بترويسة المدرسة.
- **التعاون:**
  - تعليقات مع سلاسل ردود وإشارات وحلّ التعليق.
  - بريد وارد للإشعارات، والموافقات متعددة الخطوات.
  - تقويم المدرسة، والمحادثات الداخلية، و«مهامي».
- **الإدارة:** المستخدمون والدعوات، مصفوفة الأدوار، الفروع والهيكل، إعدادات المدرسة وسياسة كلمات المرور، صندوق الإرسال، سجل التدقيق.

**معيار القبول:** «إنشاء قاعدة بيانات مخصصة بعروض متعددة والسحب بين الأعمدة بحركات الجزء ٤» ✅. يُختبر آلياً في `tests/e2e/phase1.spec.ts`: السحب يغيّر الحالة، وتتحدث العدادات فوراً، ويبقى التغيير بعد إعادة التحميل ويُسجَّل في التدقيق.

### ما لم يُبنَ أو يعمل بحدود (بصراحة)

| البند | الوضع الحالي |
|---|---|
| **خط ثمانية** | غير مطبّق. الملفات غير مضمّنة لأسباب الترخيص، ويُستخدم IBM Plex Sans Arabic بديلاً. يتفعّل ثمانية تلقائياً عند وضع ملفاته في `public/fonts/`. |
| **إرسال البريد والرسائل النصية** | لا مزوّد مربوط. الدعوات وروابط إعادة التعيين ورموز الدخول تُحفظ في «صندوق الإرسال» (الإعدادات) ولا تُرسل فعلياً. |
| **تخزين الملفات** | القرص المحلي فقط. التخزين السحابي المتوافق مع S3 غير منفّذ. |
| **Redis** | غير مستخدم. حدّ المحاولات وحضور الزملاء في ذاكرة الخادم، وهذا يكفي لخادم واحد فقط. |
| **RLS في PostgreSQL** | غير مستخدمة. العزل في طبقة التطبيق ومُختبر، ويمكن إضافة RLS طبقة ثانية لاحقاً. |
| **التحرير المتزامن** | لا تحرير لحظي مشترك. تظهر مؤشرات الحضور، والحفظ الأخير يغلب، مع نسخ سابقة قابلة للاسترجاع. |
| **مقبض سحب الكتل في المحرر** | غير منفّذ. نقل الكتل يتم بالقص واللصق. |
| **الواجهة الإنجليزية** | غير منفّذة. النصوص عربية مباشرة في الكود. |
| **المساعدون الأذكياء** | صفحاتهم تشرح قدراتهم وتوضح أنهم «غير مربوطين بعد»، والربط في المرحلة ٨. |
| **الأتمتة المجدولة (عند بلوغ تاريخ)** | تعمل عند استدعاء `POST /api/cron/automations` بالسر `CRON_SECRET`. تحتاج مجدولاً خارجياً (كل ساعة مثلاً). |
| **أولياء الأمور والطلاب** | بعد إلغاء المرحلة ٦ لا توجد بوابة خاصة. يدخلون نفس المنصة ويرون فقط ما تسمح به أدوارهم (الإعلانات والأحداث). |

## ٢. التشغيل والبيانات التجريبية

الخطوات الكاملة وجدول الحسابات في [README.md](../README.md):

- ٩ مساحات فرق.
- خطة تشغيلية من ٢٤ مهمة، وقرارات واجتماعات، ومبادرات وتوظيف وصيانة وإقفال شهري.
- أحداث ومحادثات وتعليقات وموافقات.

- تمرير أفقي غير مقصود في شاشتين على الجوال.

## ٥. افتراضات وقرارات تحتاج تأكيدك

1. **الدفع الإلكتروني للرسوم:** كان ضمن المرحلة ٦ الملغاة. هل يُنقل إلى المرحلة ٣ (المحاسبة)، أم يُكتفى بالنقد والتحويل البنكي؟
2. **ضريبة القيمة المضافة (المرحلة ٣):** النسبة ومعاملة الرسوم الدراسية للطلاب السعوديين (تتحملها الدولة) مقابل غيرهم. هل المدرسة مسجلة وتحتاج ربط الفوترة الإلكترونية (فاتورة، المرحلة الثانية) مع هيئة الزكاة؟ كل ذلك سيكون إعدادات لا قيماً مكتوبة في الكود.
3. **نظام العمل والتأمينات (المرحلة ٤):** مكافأة نهاية الخدمة ونسب التأمينات وأنواع العقود (سعودي / غير سعودي) ستكون إعدادات. نحتاج تأكيد القواعد المعتمدة لديكم.
4. **خط ثمانية:** توفير ملفات الخط بترخيص يسمح بالاستخدام على الويب.
5. **مزوّد البريد والرسائل النصية:** لإرسال الدعوات ورموز الدخول فعلياً.
6. **الأدوار الملزمة بالمصادقة الثنائية:** المالك، المدير، المحاسب، أمين الصندوق، مدير الموارد البشرية، المدقق. قابلة للتعديل لكل دور.
7. **سياسة كلمات المرور الافتراضية:** ١٠ أحرف على الأقل (حروف وأرقام)، قفل ١٥ دقيقة بعد ٥ محاولات فاشلة، وصلاحية الجلسة ١٤ يوماً. كلها قابلة للتعديل من إعدادات المدرسة.
8. **التقويم والعملة والمنطقة الزمنية:** أم القرى للهجري (العرض الافتراضي هجري وميلادي معاً)، والريال السعودي، وتوقيت الرياض. كلها إعدادات لكل مدرسة.
