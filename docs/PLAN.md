  app/
    (auth)/                الدخول، التحقق بخطوتين، إعداده، نسيت/إعادة تعيين كلمة المرور، قبول الدعوة

    collab/ inbox/ calendar/ chat/ home/ page/ settings/ misc/ auth/
  lib/
    database/              محرك مشترك بين الخادم والواجهة: التصفية، الفرز، التجميع، المعادلات، التجميعات
    rbac/                  كتالوج الوحدات، الأدوار الافتراضية، تقييم النطاقات

## قرارات معمارية

- **عزل المستأجرين في طبقة التطبيق:** امتداد Prisma يضيف `tenantId` لكل استعلام ويرفض أي محاولة لإنشاء أو نقل سجل إلى مستأجر آخر (مُختبر). لم تُستخدم RLS في PostgreSQL بعد؛ يمكن إضافتها طبقة ثانية لاحقاً.
- **التدقيق التلقائي:** كل إنشاء/تعديل/حذف عبر عميل المستأجر يُسجَّل مع المستخدم وIP والمتصفح والقيم قبل وبعد (الحقول الحساسة محجوبة). مشغّل قاعدة البيانات يمنع أي تعديل أو حذف أو تفريغ للسجل حتى من المالك أو العميل الجذري.
- **الصلاحيات = وحدة × إجراء × نطاق** (كل المدرسة / فرع / مرحلة / المسند إليه / سجلاته). المستخدم قد يحمل عدة أدوار، كل منها مقيّد بفرع أو مرحلة، والنطاق النهائي هو الاتحاد.
- **المبالغ** أعداد صحيحة بأصغر وحدة (هللة)، والتحويل من النص وإليه دون أي `float`.
- **محرك قواعد البيانات** مشترك بين الخادم والواجهة، فنفس التصفية والفرز تُطبَّق في العرض والتصدير.
