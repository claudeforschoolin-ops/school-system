# تقرير تسليم المرحلة ٢ — الطلاب والشؤون الأكاديمية

وفق صيغة التسليم في الجزء ١٧. التاريخ: ٢٩ سبتمبر ٢٠٢٦.

## ١. ما بُني وما لم يُبنَ

كل وحدة تظهر في الشريط الجانبي تحت «شؤون الطلاب» أو «الشؤون الأكاديمية» حسب صلاحية المستخدم. القوائم الكبيرة (الطلاب، القبول، الإجازات، التحويلات، السلوك، الحالات الإرشادية، الأنشطة) هي «مجموعات نظامية»: تُعرض بمحرك قواعد البيانات نفسه من المرحلة ١ بعروضه الستة والتصفية والفرز والتصدير، مع إضافة خصائص مخصصة، بينما تبقى البيانات في جداولها بقيودها وقواعدها.

### ما بُني (الجزء ٧، الأقسام ١–١٠)

| القسم | ما يعمل |
|---|---|
| **١. القبول والتسجيل** | لوحة مراحل (جديد ← مراجعة ← اختبار/مقابلة ← مقبول / انتظار / مرفوض ← مسجّل). نموذج تقديم عام برابط المدرسة (`/apply/demo`) مع رفع المرفقات وحدّ للمعدل. منع تكرار رقم الهوية بين الطلاب والطلبات المفتوحة. المقاعد المتاحة لكل صف. القبول ينشئ ملف الطالب ورقمه الأكاديمي وأولياء أمره (مع ربط الأشقاء تلقائياً). التسكين في فصل ثم «مسجّل». رسائل الاستلام والقبول والانتظار والرفض بقوالب قابلة للتعديل. تقارير (القمع، المصادر، حسب الصف) وإعدادات. |
| **٢. ملفات الطلاب** | ملف شامل بتبويبات: نظرة عامة، البيانات الشخصية، أولياء الأمور، الصحة (مع تنبيه الحالات الحرجة)، المستندات (التحقق وقائمة النواقص)، الحضور، السلوك، الأنشطة، الملاحظات، سجل التغييرات. رقم الهوية مشفّر (AES-256-GCM) مع بصمة للبحث وآخر ٤ أرقام، وكشفه كاملاً يُسجَّل في التدقيق. تقارير وإعدادات (بادئة الرقم الأكاديمي، المستندات المطلوبة). |
| **٣. الحضور والغياب** | تحضير يومي أو حسب الحصة بخمس حالات، و«الكل حاضر» بضغطة. قفل التعديل بعد ٤٨ ساعة إلا للوكيل. غياب اليوم، والسجل الشهري للفصل، والتقارير. رسائل الغياب والتأخر لولي الأمر. بلوغ حد الغياب يُنشئ ملاحظة سلوكية ويرسل تنبيهاً لولي الأمر والمرشد (مرة واحدة لكل فصل دراسي). العطل من تقويم المدرسة تمنع التحضير. |
| **٤. التحويلات والإجازات** | إجازة/استئذان باعتماد الوكيل، تنعكس تلقائياً على الحضور وتُزال إن أُلغيت. تحويل بين الفصول أو الصفوف، ووارد وصادر وانسحاب، بمسار موافقات (الوكيل ← المدير ← المالية لخلو الطرف). شهادة نقل قابلة للطباعة لا تصدر قبل خلو الطرف. |
| **٥. الإرشاد والسلوك** | ملاحظات سلوكية بالفئات والنقاط والخطورة، يسجّلها المعلم لطلاب فصوله. حالات إرشادية **سرّية**: يراها المرشد المسؤول والإدارة فقط. جلسات، خطة علاجية، واستدعاء ولي الأمر. |
| **٦. الصفوف والفصول** | الفصول حسب المرحلة والصف مع الإشغال والرائد والقاعة ونسبة المواد المسندة. إضافة وتعديل وحذف (بحماية). توزيع تلقائي بمعاينة: لغير المسكّنين، أو إعادة توزيع الكل بالتناوب حسب العمر. القاعات والمختبرات مع استخدامها الأسبوعي. **معالج إنهاء العام:** مراجعة، اختيار الباقين للإعادة، العام الجديد، ثم تأكيد بكتابة اسم العام. |
| **٧. المقررات** | كتالوج المواد (اللون والقاعة المطلوبة). الخطة الدراسية لكل صف: الحصص الأسبوعية، المواد الثقيلة، الكتاب المقرر. الوحدات والدروس بأسابيع التنفيذ. تعليم الدرس منجزاً لكل فصل (معلم المادة أو الإدارة)، ونسبة الإنجاز مقابل المتوقع مع تنبيه «متأخر». |
| **٨. جداول الحصص** | مولّد آلي بقيود (انظر «الجداول» أدناه). عرض حسب الفصل أو المعلم أو القاعة أو الطالب، مع الطباعة. سحب الحصة لنقلها أو تبديلها، مع تلوين الخانات المتاحة دون تعارض أثناء السحب. تثبيت الحصص. صينية للحصص غير المسكّنة. حصص الانتظار: تسجيل غياب معلم، واقتراح البدلاء المتفرغين، وإشعار البديل. توقيت الحصص والفسح وأيام الدراسة لكل فرع. |
| **٩. تعيين المعلمين** | مصفوفة (فصل × مادة ← معلم)، والمؤهلون في أعلى القائمة مع عبء كل منهم. أنصبة المعلمين: النصاب، يوم الراحة المفضل، المواد المؤهل لها، مع مؤشر العبء. إسناد تلقائي للخانات الفارغة. تغيير المعلم ينقل حصصه في الجدول إن أمكن. |
| **١٠. الأنشطة والفعاليات** | أندية ولجان ورحلات ومسابقات وفعاليات، بعروض: لوحة، تقويم، معرض، جدول. صفحة النشاط: التسجيل من الصفوف المستهدفة، وتحويل الزائد إلى قائمة انتظار تتقدم تلقائياً عند الإلغاء. طلب موافقة ولي الأمر برسالة وتسجيل ردّه، ولا مشاركة دون موافقة. ألبوم صور مع الغلاف، ومزامنة مع تقويم المدرسة. الرسم محفوظ بالهللة (دون float). |

### قواعد التكامل (الجزء ١٠)

| القاعدة | الحالة |
|---|---|
| القبول ← ملف الطالب ورسالة الترحيب | ✅ |
| القبول ← فاتورة رسوم التسجيل | ⏳ المرحلة ٣ (نقطة الربط `onStudentAccepted` جاهزة وتُسجَّل في التدقيق) |
| الغياب ← إشعار ولي الأمر | ✅ |
| تجاوز حد الغياب ← السلوك والإرشاد | ✅ |
| التحويل/الانسحاب ← خلو الطرف قبل الشهادة | ✅ خطوة اعتماد للمحاسب. التحقق الآلي من الرصيد في المرحلة ٣ |
| إنهاء العام ← ترفيع الطلاب وفتح عام جديد | ✅ |

### ما لم يُبنَ أو يعمل بحدود (بصراحة)

| البند | الوضع الحالي |
|---|---|
| **الفوترة** (رسوم التسجيل، رسوم الأنشطة، رصيد خلو الطرف) | المرحلة ٣. الرسوم تُحفظ وتُعرض، ولا تُصدر فواتير بعد. |
| **النجاح والرسوب آلياً عند إنهاء العام** | يحتاج الدرجات (المرحلة ٤). الإعادة حالياً باختيار يدوي للطلاب. |
| **التوزيع حسب المستوى الدراسي** | يحتاج الدرجات (المرحلة ٤). التوزيع الحالي يوازن الأعداد والأعمار. |
| **مصدر غياب المعلمين** | يُسجَّل يدوياً في «حصص الانتظار». حضور الموظفين وإجازاتهم في وحدة الموارد البشرية (المرحلة ٤). |
| **مولّد الجدول** | خوارزمية جشعة مع إصلاح بالإزاحة وعدة محاولات، وليست حلاً أمثل رياضياً. عند التعذّر تُبلغ بالحصص غير المسكّنة وسببها، وتظهر في صينية الفصل. جدول جرس واحد لكل فرع: لا يوم قصير (كالخميس)، ولا توقيت مختلف لكل مرحلة، ولا حصص مزدوجة إلزامية للمختبر. |
| **الرسائل النصية والبريد** | لا مزوّد مربوط. كل رسائل أولياء الأمور تُحفظ في «صندوق الإرسال» بالإعدادات. |
| **بوابة ولي الأمر والطالب** | لا بوابة (المرحلة ٦ أُلغيت). موافقة ولي الأمر على النشاط يسجّلها الموظف نيابةً عنه. ولي الأمر والطالب يدخلان المنصة ويريان ما تسمح به أدوارهما فقط. |
| **بيانات الحضور التجريبية** | ٢٧ يوماً دراسياً، لأن العام بدأ في ٢٣ أغسطس وأُسقطت إجازة اليوم الوطني. |
| **ألبوم الأنشطة في البيانات التجريبية** | فارغ (لا صور حقيقية مضمّنة). الرفع يعمل من صفحة النشاط. |
| **الأرقام الأكاديمية والرموز اللاتينية** | تُعرض كما هي (مثل `20240007` و`LAB-1`) لأنها معرّفات. الأرقام والتواريخ تتبع تفضيل الأرقام. |

## ٤. نتائج الاختبارات

| المجموعة | النتيجة | ما تغطيه (الجديد في المرحلة ٢) |
|---|---|---|
| `npm run test:unit` | ✅ ٧١/٧١ | مولّد الجدول (١١ اختباراً): لا تعارض للمعلم/الفصل/القاعة، الأنصبة، القاعات الخاصة، يوم الراحة، الثقيلة أولاً، المثبّت، انشغال المعلم في فرع آخر، الإبلاغ عن المتعذّر، الحتمية، فحص التعارضات. خانة التحقق لرقم الهوية، والجوال، والاسم الرباعي، والعمر. فكّ المفاتيح الفريدة المركّبة في التدقيق |
| `npm run test:integration` | ✅ ١٨/١٨ | على قاعدة حقيقية: القبول ينشئ الملف والرسالة والتدقيق ويمنع تكرار الهوية؛ حد الغياب ينشئ السلوك والتنبيه مرة واحدة؛ سرية الحالات الإرشادية؛ الانسحاب لا يُنفَّذ قبل خلو الطرف ثم تصدر الشهادة؛ الطاقة والتوزيع؛ الإسناد والتوليد دون تعارض ورفض ازدواج المعلم يدوياً؛ إنهاء العام (ترفيع وإعادة وتخرّج ونسخ الفصول)؛ الأنشطة (الانتظار والترقية والموافقة)؛ عزل المستأجرين |
| `npm run test:e2e` | ✅ ٧/٧ | إضافة للمرحلة ١: التحضير وحفظه، قبول طلب وإنشاء الرقم الأكاديمي، سحب حصة وتبديلها في الجدول، الأنشطة بعروضها. كل اختبار يعيد البيانات لحالتها |
| `npm run typecheck` | ✅ | |
| `npm run lint` | ✅ ٠ أخطاء | التحذيران المعلوماتيان نفسهما من المرحلة ١ |

اكتشفت الاختبارات والمراجعة وأُصلح:
- **خلل جدّي في طبقة التدقيق:** أي تعديل بمفتاح فريد مركّب (مثل عدّاد الترقيم) كان يفشل عند التقاط الحالة «قبل». كان يمنع إنشاء الأنشطة والطلبات المرقّمة عبر الواجهة. أُصلح بتحويل الشرط، وأُضيف له اختبار وحدة، وأُعفيت العدادات من التدقيق لأن أثرها يظهر في سجل الكيان.
- **التحضير على الجوال:** كانت أسماء الطلاب تنضغط إلى حرف واحد.
- **التوقيت والقيود:** تمرير أفقي على ٣٧٥ بكسل.
- **الرموز اللاتينية:** كانت تنقلب مع تحويل الأرقام (`LAB-1` تظهر «١-LAB»).
- **استدعاء غير نقي أثناء العرض:** نبّه له React Compiler في صفحة الحالة الإرشادية.

## ٥. افتراضات وقرارات تحتاج تأكيدك

1. **حد الغياب:** ٥ أيام في الفصل الدراسي تُنشئ ملاحظة سلوكية (−٣ نقاط) وتنبيهاً. قابل للتعديل من إعدادات الحضور. هل تعتمدون لائحة السلوك والمواظبة الرسمية بدرجاتها بدلاً من النقاط؟
2. **قفل التحضير بعد ٤٨ ساعة**، ويتجاوزه الوكيل فقط.
3. **النصاب الافتراضي ٢٤ حصة**، ويوم الراحة تفضيل وليس إلزاماً (يُكسر فقط إن تعذّر الجدول، ويظهر عدد المخالفات).
4. **المواد الثقيلة:** تُفضَّل في الحصص الأولى، ولا تتكرر في اليوم إلا إذا زادت حصصها عن أيام الأسبوع. الحد الأقصى ٤ حصص متتالية للمعلم (قابل للتعديل).
5. **الخطط الدراسية التجريبية** تقريبية لخطط وزارة التعليم (٣٢–٣٥ حصة أسبوعياً). يلزم إدخال خطتكم المعتمدة لكل صف ومسار.
6. **إنهاء العام** لمدير المدرسة فقط. يُنسخ فيه الفصول والرواد والقاعات والأنصبة، ولا يُنسخ الإسناد ولا الجدول لأنهما يتغيران سنوياً.
7. **موافقة ولي الأمر على الأنشطة:** تُطلب برسالة، ويسجّل الموظف الرد. الرحلات تتطلب الموافقة افتراضياً.
8. **خلو الطرف المالي:** خطوة اعتماد يدوية للمحاسب حتى المرحلة ٣. عندها هل يُمنع الانسحاب آلياً عند وجود رصيد مستحق، أم يبقى قرار المحاسب؟
9. **المرحلة ٣ (المحاسبة):** ما زالت أسئلة تقرير المرحلة ١ قائمة: ضريبة القيمة المضافة والفوترة الإلكترونية، ونقل الدفع الإلكتروني من المرحلة الملغاة.
