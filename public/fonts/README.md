# خط ثمانية (Thmanyah)

ضع ملفات الخط هنا بالأسماء التالية (بعد التحقق من ترخيص الاستخدام):

- `thmanyah-regular.woff2` — الوزن 400
- `thmanyah-medium.woff2` — الوزن 500
- `thmanyah-bold.woff2` — الوزن 700

يكتشف النظام الملفات تلقائياً عند الإقلاع ويولّد `@font-face` لها. إلى أن تتوفر،
يعمل النظام بالخط الاحتياطي **IBM Plex Sans Arabic** (رخصة OFL، مضمّن عبر `@fontsource`)
دون أي طلبات 404 ودون كسر التصميم.
